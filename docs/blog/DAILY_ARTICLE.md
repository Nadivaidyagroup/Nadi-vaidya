# रोज़ का स्वास्थ्य लेख — काम करने का तरीका (Claude के लिए)

हर दिन **सुबह 9:00 बजे (IST)** nadivaidya.in/blog पर एक नया लेख अपने-आप live होता है।
यह लेख एक दिन पहले शाम को लिखकर `main` पर push किया जाता है (push = deploy)। लेख में
`publish_at` होता है, इसलिए वेबसाइट उसे उसी समय से पहले नहीं दिखाती।

## कदम

1. **ताज़ा code:** `git fetch origin main && git checkout -B daily-article origin/main`
2. **तारीख़ तय करें:** अगला दिन (IST) — `TZ=Asia/Kolkata date -d tomorrow +%F`।
   अगर `api/clinic-blogs/seed/` में उस तारीख़ से शुरू होने वाली फ़ाइल पहले से है → **रुकें**, कुछ न करें।
   (अगर अभी IST में सुबह 9 बजे से पहले का समय है और आज का लेख नहीं है, तो आज की तारीख़ लें।)
3. **विषय:** `docs/blog/topics.json` में ऊपर से पहला विषय जिसका `"done": null` है।
   list ख़त्म हो जाए तो उसी शैली के नए 30 विषय (अलग-अलग category) जोड़ें, फिर पहला लें।
4. **हिंदी लेख लिखें** (मूल) — फ़ाइल `api/clinic-blogs/seed/<YYYY-MM-DD>-<slug>.json`:
   ```json
   {"slug": "<slug>", "title": "...", "title_en": "...", "category": "<key>",
    "author": "नाड़ी वैद्य क्लीनिक", "image": "/blog-covers/<slug>.jpg",
    "publish_at": "<YYYY-MM-DD> 09:00", "excerpt": "2–3 पंक्तियाँ", "content": "<HTML>"}
   ```
   - HTML में केवल `p, h2, h3, ul, li, strong, em, blockquote, br` (कोई img/script/style नहीं)।
   - 1000–1600 शब्द, सरल हिंदी, आम पाठक के लिए। ढाँचा (`api/clinic-blogs/seed/2026-11-diabetes.json` जैसा):
     परिचय → रोग क्या है → आयुर्वेद की दृष्टि (दोष, अग्नि; ठीक-ठीक पता हो तो चरक/सुश्रुत/अष्टांग हृदय का श्लोक देवनागरी में + अर्थ + अध्याय)
     → कारण → लक्षण → (जाँच, अगर लागू) → आहार: क्या खाएँ / क्या न खाएँ → दिनचर्या, योग-प्राणायाम (सावधानी सहित)
     → सुरक्षित घरेलू उपाय → आयुर्वेदिक जड़ी-बूटियाँ **सावधानी के साथ** → कब तुरंत डॉक्टर को दिखाएँ → सार → “नाड़ी वैद्य क्लीनिक में परामर्श” (करनाल 1–10, वृंदावन 11 से महीने के अंत तक, सुबह 8–1) → स्रोत।
5. **चिकित्सा सुरक्षा — हर लेख में ज़रूरी:**
   - “पूरी तरह/100% ठीक”, “जड़ से ख़त्म”, “गारंटी” जैसे दावे **कभी नहीं**।
   - जड़ी-बूटियों/दवाओं की **मात्रा (dose) नहीं** लिखनी; “वैद्य की सलाह से” लिखें।
   - “चल रही दवा अपने-आप बंद न करें” और गर्भावस्था/बच्चों/बुज़ुर्गों में सावधानी (जहाँ लागू)।
   - ख़तरे के लक्षण (red flags) जिनमें तुरंत डॉक्टर/अस्पताल जाना है।
   - आँकड़े/शोध केवल वही जो पक्के हों (WHO, ICMR, बड़े अध्ययन); पक्का न हो तो संख्या न लिखें। श्लोक पक्का न हो तो न लिखें।
   - डॉक्टरों के नाम से कोई कथन न गढ़ें।
6. **11 अनुवाद** — हर भाषा की फ़ाइल `seed/<YYYY-MM-DD>-<slug>-<lang>.json`:
   `{"slug", "lang", "title", "excerpt", "content"}`; भाषाएँ: `en pa gu mr bn ta te kn ml or as`।
   - पूरा लेख अनुवाद करें (छोटा न करें); HTML ढाँचा हू-ब-हू वही (उतने ही h2/h3/li/blockquote)।
   - संस्कृत श्लोक देवनागरी में ही, अर्थ उस भाषा में। “mg/dL”, “HbA1c”, “Fasting/PP” जैसे शब्द वैसे ही।
   - जड़ी-बूटियों के स्थानीय नाम जहाँ पक्के हों वहाँ, साथ में आयुर्वेदिक नाम।
   - फ़ाइलें बनाने के लिए Python `json.dump(..., ensure_ascii=False)` का उपयोग करें (हाथ से JSON escape न करें)।
7. **Cover फ़ोटो:**
   ```bash
   node scripts/blog-cover.cjs --out public/blog-covers/<slug>.jpg --title "<छोटा हिंदी नाम>" \
     --sub "(<आयुर्वेदिक नाम>) — <2–4 शब्द>" --chips "क्या खाएँ,क्या न खाएँ,योग,<एक और>" --category <key>
   ```
   फ़ोटो खोलकर देखें (हिंदी अक्षर ठीक दिख रहे हों, कुछ कटा न हो)।
8. **जाँच:** `python3 -I scripts/check-blog-seed.py <YYYY-MM-DD>-<slug>` → ✅ आना चाहिए। साथ में `npm ci && npm run build` (या पहले से node_modules हों तो केवल build) पास हो।
9. **topics.json** में उस विषय का `"done": "<YYYY-MM-DD>"` भरें।
10. **Commit & push to `main`** (मालिक का स्थायी निर्देश — `main` पर push = वेबसाइट deploy):
    `git add -A && git commit -m "Blog: schedule <YYYY-MM-DD> 09:00 — <English title>"` फिर
    `git push origin HEAD:main` (network error पर 4 बार तक, 2/4/8/16 सेकंड रुककर)।
    किसी और branch पर push या PR **न** बनाएँ। push से पहले `git pull --rebase origin main` करें ताकि बीच के बदलाव न टूटें।
11. **अंत में** 2–3 पंक्तियाँ सरल हिंदी में: कौन-सा लेख, किस दिन 9 बजे live होगा, link (`https://nadivaidya.in/blog/<slug>`)।

## अगर कुछ गड़बड़ हो
- push न हो पाए या जाँच पास न हो → कुछ भी आधा-अधूरा push न करें; साफ़ लिखें क्या रुका।
- पहले से लिखा लेख बदलना हो तो admin (`/admin/blogs`) से बदला जा सकता है; seed फ़ाइल दोबारा नहीं चलती।
